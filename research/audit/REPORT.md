# Независимый аудит И-Цзин

14.10.2026. База: `codex/universal-engine-v0.1`,
`3ef5e4aea1783e6cd9808766fa623a600618086b`. Исследовательская работа,
без изменения runtime, исходных восьми примеров, раскладов или журналов.

Механика пересчитана независимо от ожидаемых ответов Qwen. Все 64 номера,
шесть линий, китайские имена, пиньинь и верхние/нижние триграммы сверены
с внешними данными. В таблице спецификации расхождений не найдено;
в ожидаемых ответах примеров и подтверждённых селекторах чтения — 32
расходящихся поля. Это число полей, включая зависимые названия/селекторы,
а не число независимых ошибок.

## Файлы и воспроизведение

- [`corrected_results.json`](corrected_results.json): восемь отдельно исправленных результатов и два новых случая.
- [`discrepancies.json`](discrepancies.json): проверка каждого предоставленного Qwen поля, всех 64 строк таблицы и фрагмента «текущий raw_result».
- [`sources/reference_data.json`](sources/reference_data.json): фактические извлечения из внешних источников с закреплёнными версиями и SHA-256.
- [`sources/reading_evidence.json`](sources/reading_evidence.json): разделы, печатные/PDF страницы, URL, короткие цитаты Adler, проверка страниц Legge и редакции.
- [`sources/source_access.json`](sources/source_access.json): фактические сетевые ответы; доступность не равна проверке содержания.
- [`../../scripts/yijing_audit.py`](../../scripts/yijing_audit.py): независимый детерминированный аудит, стандартная библиотека Python 3.11+.
- [`../../tests/test_yijing_audit.py`](../../tests/test_yijing_audit.py): 15 смысловых тестов аудита.

Из корня репозитория:

```bash
python scripts/yijing_audit.py                 # воспроизвести отдельные JSON
python scripts/yijing_audit.py --check         # проверить совпадение с сохранёнными
python -m unittest discover -v
python scripts/check_yijing_sources.py --fetch # необязательная повторная сетевая проверка
```

Аудит работает также при запуске скрипта по абсолютному пути из другой директории.
Оригиналы не перезаписываются. Генератор обновляет только два JSON в `research/audit`.
Все исходные входы по-прежнему лежат в `research/qwen` без изменений; SHA-256
обоих исходников закреплены в тесте сохранности. Runtime дополнительно
проверен через `git diff --exit-code -- dis_oracle`: изменений нет.

## Пересчёт случаев

Линии перечислены снизу вверх. `6` — изменяющаяся инь, `9` — изменяющийся ян;
преобразование `6→7`, `9→8`; `7/8` сохраняются. Изменения нумеруются с 1.

| ID | Суммы монет | Изменяющиеся позиции | Исходная → преобразованная | Исправление |
| --- | --- | --- | --- | --- |
| qwen-01 | 7,7,7,8,7,7 | — | 9 → нет отдельной | Механика верна |
| qwen-02 | 6,8,7,8,7,8 | 1 | 39 → 63 | Вместо 53; шестая преобразованная линия — инь |
| qwen-03 | 6,7,8,9,7,8 | 1,4 | 47 → 60 | Механика верна |
| qwen-04 | 7,9,6,9,7,7 | 2,3,4 | 10 → 37 | Исходная 10, не 43 |
| qwen-05 | 9,6,9,6,9,7 | 1,2,3,4,5 | 37 → 64 | Пять изменений, не четыре; вместо 59 → 5 |
| qwen-06 | 9,9,6,9,9,7 | 1,2,3,4,5 | 10 → 52 | Вместо 43 → 2; верхняя стабильная линия — ян |
| qwen-07 | 9,9,9,9,9,9 | 1,2,3,4,5,6 | 1 → 2 | Особый механический случай верен |
| qwen-08 | 6,6,6,6,6,6 | 1,2,3,4,5,6 | 2 → 1 | Особый механический случай верен |
| audit-four-changes-01 | 9,6,9,6,7,7 | 1,2,3,4 | 37 → 6 | Новый случай ровно четырёх изменений |
| audit-six-changes-ordinary-01 | 6,9,6,9,9,6 | 1,2,3,4,5,6 | 47 → 22 | Новый обычный случай шести изменений вне 1/2 |

В примере 5 исходная надпись «4 изменения» сохранена как `original_label`,
но вычисленный `moving_count` равен 5. Позиция 5 не может быть стабильной.
В исходном JSON линия 6 названа преимущественной, а пояснение указывает линию 5:
это ещё одно внутреннее противоречие, не основание принять любое из правил.

Фрагмент «текущий raw_result» в спецификации содержит `...` и не является
валидным JSON. Для объявленных линий `[6,7,8,9,7,8]` правильны
`[yin,yang,yin,yang,yang,yin]`: первые две показанные Qwen полярности обратны.
Фрагмент не использовался как снимок фактического runtime.

`discrepancies.json` различает `MATCH`, `MISMATCH`, `TRANSLATION_VARIANT`,
`UNVERIFIED_COMMENTARY`, `EDITION_CONFLICT` и `BLOCKED_SOURCE`.
Варианты английского перевода не считаются ошибками монетной механики.

## Независимая сверка всех 64 гексаграмм

1. [OEIS A102241](https://oeis.org/A102241), полученный из официального
   [GitHub-зеркала](https://github.com/oeis/oeisdata/blob/5e58e93f885c5f1db9d0523b42a74cc616b16d49/seq/A102/A102241.seq),
   определяет нумерацию Вэнь-вана и явно задаёт нижнюю линию как бит `2^0`,
   верхнюю как `2^5`. Скрипт извлекает шесть битов по этой конвенции.
   Это внешняя сверка нумерации, а не только проверка уникальности.
2. [Wikipedia, редакция 1344901076](https://en.wikipedia.org/w/index.php?title=List_of_hexagrams_of_the_I_Ching&oldid=1344901076):
   извлечены имена, пиньинь, нижние и верхние триграммы для каждой из 64 строк;
   структуры дополнительно сравниваются с OEIS.
3. [Unicode NamesList](https://github.com/unicode-org/unicodetools/blob/b28e4ed4e1d4cad66ea6f6d2f7ab80db8d5188b7/unicodetools/data/ucd/dev/NamesList.txt):
   официальные английские имена символов `U+4DC0..U+4DFF`.
4. [Китайские данные ichingpy](https://github.com/JinyangWang27/ichingpy/blob/01e50a25d7b1d696ff9c8b9fa5d718a5ca0f63a8/src/ichingpy/data/iching_zh.json):
   вторичный программный набор китайских имён, ключи — линии снизу вверх.
   Его код и толкования не исполнялись и не приняты как исторический первоисточник.

Найдено 64 номера, 64 различные структуры; имена, пиньинь и триграммы таблицы
Qwen совпали с внешними извлечениями. OEIS ссылается на Knuth, vol. 4A,
§7.2.1.7, p. 486; сама книга в этом аудите не проверялась. Древние рукописи
не исследовались: проверена стандартная полученная нумерация.

Для трёх неизменяемых GitHub-файлов сетевая проверка контролирует исходный
SHA-256 и повторно извлекает факты. Для Wikipedia сохраняется SHA-256
первого ответа, но динамическая HTML-оболочка меняется даже у закреплённой
редакции: повторная проверка сравнивает все 64 фактические записи.
Исходный хеш не подменяется хешем нового ответа. TLS-проверка сохранена.

## Правила Чжу Си: проверенный источник и границы

Joseph A. Adler, *Introduction to the Study of the Changes (Yixue qimeng)*,
Zhu Xi, **Corrected edition, 2017**, [PDF](https://www2.kenyon.edu/Depts/Religion/Fac/Adler/Writings/Qimeng-3.pdf).
Издание подтверждено на PDF-с. 1. Нужный раздел — **III. Examining the
Prognostications of the Changes**, начало на с. 62, правила на с. 63–65.
Печатные номера совпадают с номерами PDF. Указанный Qwen раздел IV неверен.
Точные короткие фрагменты и хеш PDF сохранены в `reading_evidence.json`.

| Изменения | Результат сверки | Страница | Статус селектора аудита |
| --- | --- | --- | --- |
| 0 | Высказывание исходной гексаграммы | 63 | VERIFIED_SOURCE |
| 1 | Изменяющаяся линия исходной | 63 | VERIFIED_SOURCE |
| 2 | Обе изменяющиеся линии исходной; верхняя — ruler | 64 | VERIFIED_SOURCE |
| 3 | Высказывания обеих гексаграмм; первые десять вариантов дают приоритет chen, последние десять — hui | 64 | BLOCKED_SOURCE для полного селектора: порядок вариантов Figure 19 ещё не транскрибирован |
| 4 | Две стабильные линии преобразованной; нижняя — ruler | 65 | VERIFIED_SOURCE |
| 5 | Стабильная линия **преобразованной**, не исходной | 65 | VERIFIED_SOURCE |
| 6, обычная | Высказывание преобразованной | 65 | VERIFIED_SOURCE |
| 6, исходная 1/2 | Источник обсуждает using 9/6 и prognostications of both | 62, 65–66 | BLOCKED_SOURCE для полного селектора: сокращённое правило Qwen «только yong» не принято |

Для примера 6 подтверждённый селектор — линия 6 гексаграммы **52**, а не 43
или 10; для исправленного примера 5 — линия 6 гексаграммы **64**.
У нового случая четырёх изменений читаются линии 5/6 гексаграммы 6,
приоритет у линии 5. У обычного случая шести изменений — высказывание 22.
Это исследовательские указатели на тексты, не готовые трактовки и не claims.

Для трёх изменений общее чтение двух высказываний подтверждено, однако
«take the middle» не подтверждено как чтение средней линии. Приоритет не
заменён временным правилом «оба равноправны». Для заблокированных случаев
`ruling_texts=[]`, `priority=null`; интерпретация воздерживается.

## Legge: реальные ссылки и конфликт редакции

Все восемь различных ссылок из исходных примеров получены и сверены
с заголовками соответствующих гексаграмм. Старые пути перенаправляются
на новые канонические страницы; конечные URL и SHA-256 записаны в evidence.
`ic01.htm`, `ic02.htm`, `ic05.htm`, `ic09.htm` работают. Проверенные
`ic1.htm` и `ic9.htm` возвращают HTTP 404, опровергая текстовый шаблон Qwen.

[Каталог](https://sacred-texts.com/ich/index.htm) указывает `[1899]`, но
[титульная страница](https://sacred-texts.com/book/the-i-ching/title-page)
указывает `Oxford, the Clarendon Press [1882]`. Это **EDITION_CONFLICT**:
называть онлайн-корпус достоверно вторым изданием 1899 нельзя.
Отдельный [PDF Legge1882](https://www.biroco.com/yijing/Legge1882.pdf)
доступен; титульный лист на PDF-с. 10 подтверждает James Legge, Oxford,
Clarendon Press, 1882. Эти издания не смешиваются и не подменяют друг друга.

## Фактические проверки

```text
Mechanical audit: 10 cases; moving counts [0, 1, 2, 3, 4, 5, 6]
Qwen mismatching checked fields: 32
External table comparison: 64 rows; 64 unique structures; 0 mismatching rows
Zhu Xi: verified rules 0/1/2/4/5/6 ordinary; BLOCKED_SOURCE for 3 and 6 special
Interpretation: ABSTAIN; Legge corpus: EDITION_CONFLICT; runtime unchanged
Artifacts: MATCH

Ran 73 tests
OK
```

73 = 58 существующих + 15 новых тестов. Один новый тест исчерпывающе
проверил все **4096** комбинаций четырёх типов шести линий на совпадение
механики с runtime и изменение ровно указанных позиций. Отдельный тест
переставляет две записи внешнего порядка: внутренняя уникальность сохраняется,
но независимая сверка обнаруживает ошибку. Проверены некорректные монеты,
сохранность оригиналов, пять/четыре изменений, заблокированные правила,
учёт всех полей Qwen и воспроизводимость JSON вне корня репозитория.
Сообщение `ERROR: journal does not exist` относится к существующему
успешному отрицательному тесту `test_missing_db_audit_fails`.

В JSON раздельны `procedure_status=OK` (монетная механика),
`interpretation_status=ABSTAIN`, источник селектора и `claims=[]`.
Это поля исследовательского результата, не изменение контракта CoreResult
и не повышение статуса runtime-карточки.

Остаются: независимая транскрипция приоритетов Figure 19 для трёх изменений,
полная спецификация специального чтения 1/2 и разрешение конфликта редакции
онлайн-корпуса. Предсказательная эффективность этими тестами не проверялась.
