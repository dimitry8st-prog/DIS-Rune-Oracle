## Фактические проверки

Из корня checkout, Python 3.12.14:

```bash
python -m unittest discover -v
python -m research_stats distribution
python -m research_stats report research/science/examples/synthetic_study.json
python -m research_stats simulate --n 1000 --seed 20261016
python -m research_stats.design
python research/science/verify_sources.py --cache-dir /tmp/dis-science-rechecked
git diff --exit-code -- dis_oracle docs examples research/qwen .github pyproject.toml
```

Фактический результат unittest:

```text
Ran 80 tests
OK
```

58 существующих + 22 новых теста. Включены полный перебор **4845** исходов
одного поля, точные нормировки совместного распределения/суммы, раздельный
подсчёт полей, невалидные числа/дубли, несогласованные ID/времена,
исключение поздних/ретроспективных/неподтверждённых прогнозов, сохранение
воздержаний и пропусков, точный тест знаков с ties, ненулевая неопределённость,
Brier/запрет поддержки как вероятности, фиксированный порог плана,
воспроизводимость seed, read-only поведение и CLI с ненулевым кодом при ошибке.
Существующее сообщение `ERROR: journal does not exist` — ожидаемый успешный
отрицательный тест, не ошибка серии.

Синтетический отчёт содержит **8 событий, 16 слотов, 2 допустимых результата
метода, 7 контроля, 2 общие пары**. Нулевые попадания учтены; недостающие
данные не превращены в промахи. Контроль на семи событиях не сравнивается
с методом на двух как независимая или одинаковая выборка.

Для плана бинарного опыта вычислено `N=1000`, успехов ≥542,
нулевой хвост `0.0043199745011302665`, мощность при p=.56
`0.8806228420448081`. Это математический расчёт при предпосылках, не результат
сбора данных. Расчёт проверяет минимальность порога: 541 недостаточно.

Повторная проверка источников: **9 HASH_MATCH** (8 PDF и RFC-текст),
**5 HTML_FETCHED_CONTENT_REVIEW_NOT_REPEATED**. HTML может менять оболочку;
заново полученная страница не объявляется автоматически научно проверенной.
Первый ручной просмотр содержания и SHA каждого ответа сохранены отдельно.
Две нерабочие начальные ссылки (404) не скрыты и не используются как основания.
Проверки TLS и исходные контрольные суммы сохранены.

Файлы примеров в `examples/` воспроизводятся соответствующими CLI-командами;
реальные пользовательские записи туда не добавлялись. Для реальной выгрузки
нужно сохранить все заранее допустимые попытки и свидетельства происхождения,
а не восстановить удобный набор по фрагментам беседы.

**Технические тесты не доказывают прогнозную эффективность. Гипотеза обратного
потока времени остаётся непроверенной.**
