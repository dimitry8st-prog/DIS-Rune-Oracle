# Методика DIS Rune Oracle

Сверено 12.10.2026. Ниже сохранена методика **рунического адаптера v2.1** от 09.10. Она не является полной методикой десяти ядер.

Наша цель — создать Оракул, объединяющий символические традиции и научную проверку, чтобы исследовать возможность предсказания будущего со снижением измеряемой ошибки, проверить гипотезу обратного потока времени и выяснить природу удачи, отличая её от случайности.

Универсальный контракт: [архитектура](ARCHITECTURE_10_CORES.md); реализация и запуск: [движок v0.1](ENGINE_V0_1.md). Универсальное ядро принимает карточки; в [v0.2](ADAPTERS_V0_2.md) реализованы закрытый выбор, RNG, commitment и фиксированное современное руническое чтение. Дополнительные слои ниже относятся к руническому адаптеру; культурные ядра и их веса определяет архитектура.

## Ядро

24 знаковые руны и один Пустой знак. Выбор трёх разных элементов без возврата: I → II → III. До третьего выбора элементы закрыты; выкладка III ← II ← I. Открытый вопрос фиксируется дословно; приватный вопрос остаётся у пользователя.

Слои выбираются до расклада. По умолчанию включены только три позиции, один рефлексивный вопрос и один проверяемый шаг. Нельзя добавлять слой после исхода ради подгонки.

## Режимы

| Режим | Что требуется |
| --- | --- |
| Физический | Набор пользователя; фактические знаки и ориентации сообщает пользователь |
| Проверяемый цифровой | Надёжный RNG, скрытое состояние между ходами, канонический манифест, nonce и реальное вычисление SHA-256 |
| Симуляция | Явная маркировка; нельзя заявлять предварительную фиксацию или проверяемую случайность |

В физическом режиме исходную ориентацию можно восстановить из итоговой только когда пользователь сообщает действие 0°/180°. Если действие или положение неизвестны, так и указать; не выдумывать протокол.

## Цифровой контракт

Канонический текст — UTF-8 без BOM, переводы строк LF, без завершающего LF:

```text
version=2.1
nonce=<случайный nonce>
01|<rune_id>|<0/180/NA>
...
25|<rune_id>|<0/180/NA>
```

Для реализации предлагается CSPRNG, перемешивание без смещения и независимые ориентации 0°/180°. Каждый rune_id встречается ровно один раз; для Пустого знака используется blank и NA. nonce должен содержать не менее 128 случайных битов. Это техническое требование, а не описание выполненной реализации.

Commitment — SHA-256 точных байтов текста. До выбора показать только хеш и закрытые временные номера. После чтения раскрыть весь исходный манифест и nonce. Выборы и повороты сохранить отдельно. Хеш проверяет неизменность раскрытого набора; качество генератора требует собственной проверки.

Формула итоговой ориентации знаковой руны: `(base + rotation) % 360`. Для blank вычисления ориентации нет.

## Дополнительные слои

| Слой | Правило |
| --- | --- |
| Контекст дня | Реальные дата, сроки, ресурс и состояние; астрологические соответствия допустимы лишь как явно названная авторская метафора |
| Вектор согласования | Какие условия учитывать и что зависит от пользователя? Не утверждать, что «мир требует» определённого поступка |
| Точка перехода | Наблюдаемый признак смены ситуации; срок определяется фактическими условиями, а не руной |
| Фаза цикла | Современная метафора зарождения, роста, созревания или завершения; без автоматического обещания нового витка |
| Числовой слой | Сумма постоянных индексов рун 1–24, blank = 0; при трёх разных элементах диапазон 3–69. Значение суммы не валидировано, готовой шкалы нет |
| Дополнительный выбор | Только отдельный ракурс с заранее заданными правилами; не подтверждение и не отмена первого чтения. До разработки собственного протокола цифровой вариант выключен |
| Рефлексивный вопрос | Один нейтральный вопрос, допускающий несогласие с чтением и альтернативное объяснение |

Постоянный индекс в числовом слое не равен временному номеру закрытой костяшки. Числовой слой выключен по умолчанию. Не сворачивать сумму в диапазон 1–24 без отдельно утверждённой методики.

## Границы культурной атрибуции

Традиции исследуются в культурном корпусе отдельно от алгоритма. Сходство механизма не доказывает происхождение метода. Формулировки «древнеегипетская энергия планетарной недели», «славянская сумма номеров рун» и «единая масонско-иллюминатская школа» не используются без профильных источников. Слой цикла называется нейтрально; религиозные названия не служат авторитетом для вывода.

## Результат

1. Технический протокол, если он доступен.
2. Чистое чтение знаков и позиций.
3. Отдельные включённые слои.
4. При известном вопросе — прикладная интерпретация.
5. Известные факты, новая перспектива, гипотеза и альтернативное объяснение.
6. Обратимый шаг, срок проверки и опровергающий признак.

Первоначальное чтение не переписывается при раскрытии вопроса или исхода. Изменение формулировки сохраняется отдельной записью с объяснением.
