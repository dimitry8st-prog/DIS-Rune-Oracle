## Реализовано

Общий `Cycle` и CLI: регистрация manifest → четыре существующих адаптера →
валидация полных input_hash → явная ручная приёмка claims → десять весов 0.10 →
исходный отчёт → отдельная научная версия → ожидание → исход/контроль/новая
научная версия. [Команды и точные границы](INTEGRATED_ENGINE_V0_3.md).

Зафиксированный manifest, привязка event_id/run_id, общий lock и отдельные
сессии защищают от смены входов, повторного жребия при перезапуске и локального
перебора run_id одного события. Восстановление после прерывания проверено как
между адаптерами, так и между приватной записью подтверждения и общей записью.
Ручной отказ Гуань Инь сохраняется без перевыбора. Исторический режим блокируется.

Научный интерфейс вызывает `research_stats.core.report` и `paired_summary`,
сохраняет исходник расчёта по хешу и отдельные версии с причинами. Сам код
статистики PR3 не изменён. Полный двухполевый импорт — дополнительный явно
зафиксированный внешний метод, не результат выдуманной формулы по символам.

Исправлены два интеграционных дефекта: порядок карточек теперь задаётся списком
CORES, а не порядком ключей JSON; при повторе старого freeze его input_hash
проверяется с **сохранённой** версией engine, поэтому обновление пакета до 0.3.0
не отвергает неизменённую запись v0.2. Старый отчёт/версия не пересохраняются.
JSON CLI теперь также отвергает дубли ключей и нечисловые константы NaN/Infinity.
Пакет wheel включает научный модуль и учебный ресурс.

## Исследовано / заблокировано / не проверено

Пять направлений [научной карты](../research/science/SCIENTIFIC_MAP.md) и проект
опыта будущей независимой случайной цели сохранены. Физические теории,
математические модели, интерпретации и неподтверждённые гипотезы не смешиваются.
Теория игр отложена. Эксперимент по времени спроектирован, не проведён.

Нет проверенных корпусов Мо/Гуань Инь и закреплённого runtime-чтения И‑Цзин;
нет подтверждённых правил Kwan Im Thong Hood Cho Temple, независимой TSA,
аутентификации рецензента/исходов, полной выгрузки реальных опытов и внешнего
контролируемого повторения. На момент аудита v0.3.1 исходника lottery-rune-hash-v2 в проверенных ветках не
было. Сейчас формула подключена как отдельный авторский метод: план до генерации,
неизменяемая пара после сохранённой рунической сессии, прежний импорт
numeric_study без автоматической подмены. Метод не становится одиннадцатым ядром.

Нет автоматической числовой формулы по символам, подстройки весов, вызовов LLM
или физической петли времени. Агрегация независимых реальных событий в единое
пререгистрированное исследование остаётся отдельной задачей; научный отчёт v0.3
имеет область одного события и явно сохраняет пропуски/отказы.

**Технические тесты не доказывают прогнозную эффективность; гипотеза обратного
потока времени остаётся непроверенной.** PR предназначен для проверки и не
объединяется автоматически.
