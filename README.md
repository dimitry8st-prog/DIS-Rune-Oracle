# DIS Rune Oracle

**Рунический оракул различения — самостоятельный исследовательский проект ДИС.** Символический разбор ситуации, прозрачная процедура выбора и проверка следующего шага.

Проект исследует, помогает ли сочетание символов и структурированных вопросов человеку находить альтернативные объяснения и принимать более осмысленные решения. Польза для мышления и точность прогнозов оцениваются раздельно.

**Статус:** разработка методики. В репозитории подготовлены документы и черновик кейса. Приложение, цифровой генератор, Telegram-бот и исследовательский дневник ещё не реализованы; эксперименты не проводились.

## Как устроен замысел

24 руны Старшего Футарка и Пустой знак как современный метасимвол. Пользователь выбирает три закрытых элемента; чтение фиксируется до проверки результата.

| Позиция | Вопрос |
| --- | --- |
| I — ситуация | Какие аспекты ситуации стоит рассмотреть? |
| II — курс | Какое направление действия можно исследовать? |
| III — возможное изменение | Что может измениться при выбранном действии? |

Выкладка: **III ← II ← I**. Названия позиций задают вопросы для размышления; они не устанавливают фактическое состояние внешнего мира.

Вопрос можно сообщить заранее или оставить приватным. Дополнительные слои включаются по желанию до выбора. Практический итог — гипотеза, обратимый шаг и признак, по которому можно проверить результат.

## Планируемый минимальный прототип

1. Детерминированный модуль выбора и ориентаций с надёжным RNG.
2. Commitment: SHA-256 скрытого манифеста с nonce, раскрытие после чтения.
3. Ограниченный AI-помощник для объяснения символов без доступа к реальным действиям.
4. Приватный дневник гипотез и наблюдаемых исходов.

Для ручного пилота достаточно физического набора и дневника. AI нужен для формулировок и сравнения интерпретаций; он не является источником сведений о будущем.

## Границы

Это современная авторская методика. Культурные аналогии не доказывают её древность или эффективность. Пустой знак не представлен как историческая 25-я руна. Криптографическая фиксация подтверждает неизменность набора, но не истинность толкования. Профессиональные решения требуют проверки фактов.
