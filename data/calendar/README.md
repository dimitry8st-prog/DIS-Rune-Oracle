# Локальный корпус Каирского календаря

Файл `cairo_calendar_prognoses.json` в этом каталоге игнорируется Git и не входит
в устанавливаемый пакет. Движок не скачивает его автоматически. Без файла
египетский профиль возвращает ABSTAIN; японский работает независимо.

Схема локального файла:

```json
{
  "schema_version": "cairo-calendar-prognoses-v1",
  "source_ref": "https://example.org/your-source",
  "rights_notice": "Укажите действительные условия источника; не приписывайте CC0",
  "rows": [
    {"month": 1, "day": 1, "segments": ["G", "G", "G"]},
    {"month": 1, "day": 2, "segments": [null, null, null]}
  ]
}
```

Это пример схемы, не историческая таблица. `month` — целое 1..12, `day` — 1..30.
Читаемая строка имеет ровно три G/S, неизвестная — ровно три null; частичные null
отклоняются. Пустые и неполные корпуса допустимы как частичные данные: отсутствующая
позиция всегда ABSTAIN. Дубликаты ключей JSON и дат отклоняются. Программа сохраняет
SHA-256 исходных байтов, URL и `rights_notice`, но не удостоверяет их истинность.

Основной исследовательский источник: [Jetsu et al. 2013, таблица 1](https://www.mv.helsinki.fi/home/jetsu/papers/algol1.pdf).
Его полный текст и полная извлечённая таблица не включены в публичный репозиторий.
Путь по умолчанию предназначен для работы из checkout; установленный wheel без
корпуса также корректно возвращает ABSTAIN. Перевод современной даты в египетскую
не выполняется: соответствие указывается в профиле отдельно.
